# Refugio Huellitas - TFI

Trabajo Final Integrador de Web1: sitio web institucional del refugio de perros realizado con HTML, CSS y JavaScript.


## Descripción del sitio

Refugio Huellitas es una plataforma web orientada a concientizar sobre la tenencia responsable de mascotas y facilitar la adopción de perros rescatados. El sitio organiza a las mascotas en categorías por edad (Cachorros, Adultos y Ancianos), incluye una sección informativa sobre el refugio y cuenta con un formulario interactivo con validación de datos para la recepción de solicitudes.

## Cómo usar el sitio

Desde el menú de navegación superior se podrá visitar el inicio, consultar los perritos disponibles en la sección de adopciones y acceder al formulario de contacto donde elegirás el motivo por el cual deseas ser contactado por nosotros, ya sea adopción u otras formas de colaborar con el refugio.
